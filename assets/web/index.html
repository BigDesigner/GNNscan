The engine already resolves MAC vendors offline using a bundled local OUI database sourced directly from the IEEE public registry (~39,700 prefixes). Enable this only if you want a live fallback query to macvendors.com for prefixes missing from the local database.

WARNING: when enabled, unresolved MAC address prefixes of scanned devices are sent to a third-party server (macvendors.com) over the internet. This breaks fully-offline/air-gapped operation and may not be permitted on sensitive networks. Enabling this is done at your own risk and responsibility. Default: OFF.
